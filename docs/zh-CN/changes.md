# 简中版修改记录

## 0.4.0-zhCN.1

以 [Mobile Codex v0.4.0](https://github.com/nokryong/mobile-codex/releases/tag/v0.4.0) 为基础。

- 新增简体中文语言目录，首次打开默认使用简中。应用内语言选择保留英文、韩文和跟随系统。
- 新增 1,551 条简中本地化项，覆盖导航、按钮、设置、账户、登录、审批、语音、错误提示与任务通知。保留运行时插入的账户、模型和命令等变量。
- 为原生 Android 无障碍服务说明、用量小工具及相关日期和时长补充简中文案。主界面与原生 Android 代码使用同一套翻译内容。
- 调整启动器显示名称为「Mobile Codex 简中版」，使用独立应用 ID `dev.mobilecodex.app.zhcn`。
- 保留上游 Codex、Python、Node.js、Git 和可选 Linux 环境的运行机制及第三方许可声明。

## 验证范围

校验了简中翻译表及 Web 和原生字串的一致性，检查了插值变量，运行了浏览器语言切换验证，并在一加设备上安装、启动和抽查简中登录及设置页面。翻译使用了机器翻译辅助，常用入口及关键授权与登录文案做了人工校对。第三方账号的端到端登录、每种系统通知的实际送达和长尾异常页面尚未在真机逐项验证。
